# network-graphs

NetworkX network models and graphics. Each model lives in its own folder with
its own README.

| Model | Description |
|---|---|
| [backbone5](backbone5/) | Backbone1 core + edges with estimated per-link latency |
| [lowlatency-plan1](lowlatency-plan1/) | Low Latency Prem-to-Cloud Plan1: 10-site backbone with AWS and Internet on-ramps, one line per circuit, NJ Metro and London region boxes, per-circuit one-way latency on diverse paths, and a KMZ of every path |
